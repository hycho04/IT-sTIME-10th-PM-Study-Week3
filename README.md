# WATT IF · 화면·기능 통합 문서와 Live Demo

WATT IF의 화면 정의서, 기능명세서, 문서용 와이어프레임 미리보기와 실제 조작 가능한 React 데모를 한 사이트에서 확인할 수 있습니다. 팀원이 같은 화면 ID·기능 ID를 기준으로 기획 의도와 구현 결과를 함께 볼 수 있도록 만들었습니다.

Notion에 붙여 넣어 팀원들과 공유할 수 있는 워크숍 가이드는 [NOTION-GUIDE-KR.md](./NOTION-GUIDE-KR.md)에 있습니다. 다른 프로젝트에서 같은 문서 사이트를 만들 때 쓸 한 번 입력용 통합 프롬프트와 배포 안내는 [GUIDE-KR.md](./GUIDE-KR.md)에 있습니다.

## 메뉴

- **전체 흐름 보기:** 12개 화면의 작은 정적 미리보기와 진입·종료 경로를 확인하고, 문서 보기와 시연하기를 각각 독립적으로 엽니다.
- **문서 보기:** 작은 Figma 프레임, 원형 번호가 붙은 구성 요소, 화면 설명과 기능명세를 세로로 읽습니다. 프레임 번호를 누르면 같은 문서 안의 설명으로 이동합니다.
- **시연하기:** 문서와 독립된 실제 React UI에서 캠핑 설정, 프리셋, 차량 제어, 종료·점검 흐름을 조작합니다.

문서의 Figma 번호를 선택하면 같은 문서 안의 대응 설명으로 이동합니다. 시연하기는 문서와 별도로 조작하는 독립 화면입니다. 전체 흐름 보기에서 문서와 시연에 각각 진입할 수 있습니다. 화면 정의의 원문은 Notion 페이지로 연결됩니다.

## 자료와 와이어프레임 범위

화면 12개와 기능 17개는 제공된 Notion 데이터베이스 스냅샷 `src/specData.json`에서 가져옵니다. 앱은 원문에 기록된 화면 ID, Feature ID, 목적, 경로, 주요 구성, 주요 동작, 상태·예외, 기능 유형·중요도, 데이터 로직과 제한사항을 표시합니다.

제공된 Figma 내보내기 코드의 화면 프레임 01–11을 분리해 각 화면 문서에 표시합니다. 화면 문서의 ID와 Figma 프레임 번호를 연결했으며, Figma 프레임 01–11은 원본 화면 번호입니다. Notion 화면 정의의 구성 요소 목록에는 별도 번호가 없어 그 목록을 순서대로 참조합니다. Notion에만 있는 SCR-012는 제공 코드에서 대응 프레임을 찾지 못해 와이어프레임 미제공으로 표시합니다. Figma 프레임 링크 자체는 제공 자료에 포함되지 않았습니다.

프리셋 실패 동작은 Figma 프레임 10과 Notion 화면 명세가 다릅니다. Figma는 성공 항목을 유지하고 실패 항목을 재시도한다고 설명하고, Notion은 전체 설정을 복원한 뒤 프리셋 전체를 다시 적용하도록 정의합니다. 문서에서 두 원문을 함께 표시하고 결정이 필요한 정책으로 남겼습니다. Notion 원문에 별도 필드가 없는 Actor, Trigger, 선행 조건, QA 기준도 임의로 채우지 않고 미기재로 표시합니다.

## Demo 데이터와 제한

정적 Live Demo이며 실제 차량 SDK, 날씨 API, 지도/목적지 API, RoomDB 또는 서버와 연결하지 않습니다. 차량 상태·날씨·목적지 거리·캠핑 기록은 `src/mockData.ts`와 화면 상태로 제공합니다. 야간 모드 외의 진행 중 캠핑 상태는 새로고침 후 유지되지 않습니다.
